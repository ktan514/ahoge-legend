# 三動作の実装・検証記録

関連: #102 / PR #105 / `AHOGE_WHIP_MOTION_DESIGN.md`

## 実装範囲

チャージ・ムチ打ち・近距離パリィをすべて実装対象とする。パリィだけを完了として扱わない。

- `AhogeActionMotion`: 後方への垂れ、根元側から毛先への解放、現在形状からパリィと復帰への接続。
- `AhogeMeshDeformer.set_action_pose`: 固定したUV/index/RIDを維持した頂点更新。
- `BattleFighterVisual`: 同じ攻撃時計で接触姿勢と振り抜きを制御し、パリィは近距離専用に切り替える。
- `ahoge_mesh_action_test.gd`: 24条件の実描画。従来の接触48条件とパリィ48条件も維持する。
- `verify_action_report.py`: 結果・条件数の照合と保存した実形状の外周検査。

## 設計の適用差分

設計初期値BACK_BEND=-1.4 radでは1600x900の溜め姿勢が後方の余白を超え、画面保護が約0.895まで全体を縮めることを実描画試験で検出した。1280x720でも約0.998となった。

この問題をしきい値緩和や全体縮小で隠さず、曲げ形状側で修正する。

- **BACK_BEND=-1.15 rad**を採用する。末端の垂れTIP_DROP=+1.8 radと弧長方向の分布は維持する。
- チャージ中に追加のreachやscale倍率を入れない。
- 頭部の後退量とレイアウトを射程・余白のために増やさない。
- 最大溜めで毛先がrootより後方、待機時より下方へ移る条件を維持する。
- 長押し保持中の形状収束、弧長、断面幅と画面保護倍率>=0.999の合格条件を維持する。

本差分を `AHOGE_WHIP_MOTION_DESIGN.md` の初期曲げ値より優先する。
