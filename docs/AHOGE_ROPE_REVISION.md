# ロープの曲がり伝播・下向き通過の再修正

関連: #102 / PR #105。基準は b671a9554963eaaf53c0d0d35d7c228ed7146673。
上位要件は AHOGE_WHIP_PROJECTION.md。実機NGは継続し、以下は実装方針であって見た目の合格記録ではない。

## 形状

- チャージは旧C字へ曲げを足して末端を巻き込む方式から、根元の接続部を残す開いた後方アーチへ変更する。区間長と断面幅を保存する。
- 攻撃は区間ごとの解放に、中央から先端へ移る幅のある曲げの帯を重ねる。接触時に末端の巻き込みをほどく。瞬間の直線姿勢を全動作へ使い回さない。
- 接触後も区間ごとの角度は変化を続け、根元側の引き戻しと先端側の遅れを異なる時刻にする。接触後に直線のまま縮める動作を主成分にしない。
- パリィは根元側62%を固定し、曲げを首に相当する短い遷移帯へ分布させる。先端側の曲がった毛束の形をより保って、短い弧を払う。

## 時間と通知

- サーバーとCombatConfigに存在する通常/最大チャージの時間差を使用する。離してから接触までを速くする要件で、連打速度やCOOLDOWN短縮ではない。既存時間値を新規実装したとは報告しない。
- 接触後の経路は開始速度0のsmoothstepを使用せず、初速度を持つ減速曲線で下へ通過してから戻す。
- 既に接触を通過した攻撃に遅延Hitが来ても、姿勢・時計・固定した接触点を巻き戻さない。接触前の確定通知だけ追従する。古い攻撃・中断・非表示の抑止を維持する。
- 振り抜き中は相手を追尾しない。画面内包含・幅・根元・接触2pxの契約を維持し、危険な形状を縮小で隠して合格にしない。

## 検証

従来検査に加え、開いた溜め形、毛束に沿う曲率の時系列変化、接触後の速度、遅延Hit対照、通常/中間/最大チャージの時間差を検査する。
描画動画は等倍とスローを分ける。幾何学とCIが通っても実機Human Verification・独立最終レビューは別であり、PRをマージしない。

## 適用する値と既存仕様の差分

本節は AHOGE_WHIP_PROJECTION.md の旧全体補正値、および AHOGE_ACTION_IMPLEMENTATION.md の旧後方曲げ値より優先する。

- 後方アーチは区間角 -1.30から-4.30radへ開き、弧長8〜22%で根元の元形状へ接続する。C字から移る途中だけ広い曲げを残し、長い直線となって画面上端へ出ることを防ぐ。
- 攻撃前半の曲げ帯は弧長方向0.18→1.13へ進む。最大0.60rad、幅0.24。接触時には帯を抜ける。
- 接触後の曲げ帯は0.20→0.88へ進む。振り抜き0.16秒の間に1.10→0.78radへ変え、末端に下向きの追加曲げをつなぐ。一定の微小角度を足すだけの処理は使わない。
- 接触前の射程補正は smoothstep(0,0.90,q) の通常1.8乗〜最大チャージ2.8乗。接触直前には全体の伸長を落ち着かせ、毛先の移動を残す。
- 接触前に下へ入射する弧を用意し、接触後の進行2u-u²へ接線をつなぐ。接触後0.16秒の前下通過の後に回収する。クライアント上の曲線接続であり、オンライン遅延下の完全な速度一致を保証する記述ではない。
- パリィの局所曲げは弧長62〜80%へ分布。80%より先は区間間の曲率を維持して毛束を返す。払い角度-0.72rad、根元側固定は維持する。全体回転や射程増加で大きく見せない。
