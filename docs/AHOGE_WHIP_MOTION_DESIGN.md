# アホ毛の溜め・ムチ打ち・近距離パリィ

関連: #102 / PR #105。基準: `a5dc5fdba3047a7841360fb75afbd56c8189e91f`。

## 要求・対象範囲

人間さんの「全部対応」により、今回は三動作をすべて実装対象とする。

- チャージ: 頭部に根元を固定し、中間から先端を後方・下方へ垂らす。画像全体の回転だけで代用せず、長押しで巨大化させない。
- 攻撃: 根元側から中央、先端へしなりを解放する。先端までほどいた状態で接触し、相手に貼り付けたままにせず振り抜く。
- パリィ: 湾曲を残し、自分の近くで先端側の短い毛束だけが払う。全体の大振り、長距離伸長、相手頭部への追従は不採用。

2D頭部・現行PNG・427頂点/680三角形・UV/index/RIDを維持する。server authoritativeの時間、Hit/Defense/Just/Clash/Rating、両者切断無効試合は変更しない。SHORT投擲をLONGのムチへ置換しない。通常GameFlowのみを使う。

## 共通の形状制御

`AhogeActionMotion` が三動作の現在状態、経過時間、移行時の曲げ状態を保持する。毛束に沿う断面の中心線と弧長を初回にキャッシュし、各区間の角度だけを変える。元の区間長と断面幅を維持し、断面内の頂点を中心線の接線変化に合わせて回す。

全体Transform2Dと形状制御を分離する。前frameの接触補正のskewを次frameの基準に持ち越さない。描画バッファを更新してもUV/indexと素材は変更しない。

基準・仮パラメータは専用motion moduleの定数へ集約する。これらは見た目専用であり、サーバーの射程や強さを決めない。

## チャージ・後方への垂れ

弧長比率sに沿い、根元側を固定しつつ、中間の後方曲げと毛先側の下向き曲げを組み合わせる。

初期形状目安:
- 後方曲げ: -1.4 rad、弧長7〜30%で滑らかに増加。
- 末端の垂れ: +1.8 rad、弧長40〜97%で滑らかに増加。
- これらは全体回転角ではなく、rest中心線の各区間への追加角度。
- チャージの進行を根元側ほど早く、先端側ほど遅く伝える。
- 最大チャージ後は一定姿勢に収束。追加reachなし。

CHARGING→WINDUP→STRIKEで現在の角度場を引き継ぎ、間にC字を挟まない。短い通常攻撃のWINDUPにも小さい後方たわみを用意する。

## 前方攻撃・ムチ打ち

`RootLead → MidArc → TipRelease → Contact → FollowThrough → Rest`。
STRIKEから接触までの正規化時間qを使い、弧長に応じた開始/完了時刻で後方形状から既存の直線方向へ解放する。根元側の解放を先に終え、毛先側は接触直前までカーブを残す。各区間の解放速度ピークが根元側→中央→末端の順になるようにする。

通常0.20秒、最大チャージ0.13秒、contact_ratio=0.70を既存Configから取得する。別の攻撃時間を追加しない。

全体の向きと距離も同じ攻撃時計で動かす。根元を支点として向きを合わせ、根元→先端軸にだけ必要な距離補正を掛ける。接触時は実メッシュ最先端と相手の表示輪郭との誤差2px以下を維持する。幅方向を射程倍率で潰さない。

接触後は目標位置を固定し、短い前方・下方の振り抜き軌道へ移る。相手の頭部を追尾・保持し続けない。COOLDOWNは実際の現在形状と表示transformからC字へ復帰する。入力による突発的な再構成や前の攻撃の再発を避ける。

## パリィ・湾曲を保つ先端払い

既存`AhogeParryMotion`の末端局所変形を三動作の制御へ接続する。
- 根元〜弧長62%のパリィ追加変位は0。
- 62〜94%で追加曲げ量を滑らかに増やす。
- 準備/払い/反動は +0.12 / -0.42 / +0.06 radを初期値とする。
- 最先端一点だけでなく、その手前を含む毛束を一度鋭く返す。
- PARRY時間0.18秒・Just時間0.07秒は変更しない。
- 頭部のきっかけは数px。全体の上下ジャンプは使わない。

攻撃・溜め途中からのPARRYでは、現在の区間角度から0.055秒で湾曲C字へつなぎ、その上に局所払いを加える。頂点配列の一括直線補間で面を潰さない。解除後の残り曲げは0.08秒で解く。

PARRY中は相手頭部への接触補正を使わず、古いHit通知も受け付けない。防御成功はserver結果のみを根拠とし、入力から成功を捏造しない。

## 責務・優先順位

1. 非表示/ROUND_LOCKED: 古い形状と接触を解除。同一STRIKEへ再表示しても再発させない。
2. PARRY: 近距離先端払い。攻撃の接触補正より優先。
3. CHARGING/WINDUP: 後方形状と現在姿勢の継承。
4. STRIKE: しなり解放と接触、振り抜き。
5. COOLDOWN/DODGE/STAGGER: 現在姿勢から復帰。

`BattleContactDirector`が両頭部を更新した後に表示を確定する。既存FighterVisual/PrototypeRigの単体描画は互換性のため残すが、Battleの三動作はActionMotionを正とする。

## 検証

新しいパリィ試験は空のSceneTreeだけで終了する構造を許さず、実行した条件数・assert数・結果ファイルを必須にする。過去の空試験によるCI成功を今回のパリィ検証へ流用しない。

- 後方・下方への頭部相対変位、保持中の弧長と幅、非巨大化。
- 区間ごとの解放順序、接触前の末端カーブ、接触時の先端方向。
- 接触誤差2px、画素差、断面幅、根元固定、頭部横端/全頂点の画面内包含。
- 接触後の先端の移動と追尾停止。
- パリィの固定部と動く末端、曲率、相手頭部に伸びないこと。
- 左右・30/60/120fps・1280x720/1600x900、通常/最大チャージ、長押し保持、各状態からの中断。
- 面積・境界交差と実描画、歪み累積防止、既存48接触条件、オンライン回帰。
- 等倍の連続描画とスロー補助を保存し、Mac通常GameFlowでHuman Verificationする。

サンプルでの幾何学検査を連続全域の証明とは扱わない。三動作のコード反映、各試験、Human Verificationを個別に記録する。Human Verificationと独立最終レビューが未完了ならPR #105はマージしない。
