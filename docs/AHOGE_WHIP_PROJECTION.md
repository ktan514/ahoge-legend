# ムチ打ちの全体補正

関連: #102 / PR #105 / AHOGE_WHIP_MOTION_DESIGN.md

## 実描画の確認からの追加修正

三動作の条件が通ったことと、ムチ打ちの時系列品質を分けて確認する。
旧試行では、毎frameの曲がった毛先方向を相手へ回す補正により、最大チャージの序盤で中央と先端が同時に大きく動いていた。区間角度の解放順序だけでは、最終描画の速度順序を保証できない。

## 修正する基準

- 回転・軸方向伸長の基準は、そのframeで巻き込んだ毛先ではなく**接触時の伸び切った形の根元→先端ベクトル**に固定する。
- 現在の毛束の形はActionMotionの根元側→中央→末端という解放に任せる。曲がった毛先を毎frame目標方向へ直接回す処理で上書きしない。
- 接触までの進行qに対する追加射程補正は、通常q^4・最大チャージq^6とする。中間チャージは指数を4〜6で補間する。
- 全体回転はsmoothstep(0,0.95,q)で接触時の向きへ展開する。
- 接触時q=1では現在形と基準形が一致し、先端位置誤差2px以下を維持する。
- 接触後は固定した接触点から前方30px・下方22pxへ振り抜く。相手追従は再開しない。
- 幅方向へ追加射程倍率を掛けず、原点を動かさず、skewを次frameへ累積しない。

q^6を通常攻撃にも共用した試行では、中央と先端の最大前方速度が同じ接触frameになった。通常をq^4にして中央の先行と先端の終盤加速を両立させる。指数の調整でサーバー時間を変更しない。

## 検証

既存の24連続動作・48接触・48パリィの基準は維持する。出力する時系列traceのroot・middle・tipの前方速度も確認し、角度場の順序だけを根拠にムチ動作完了としない。

通常/最大チャージ、左右、2解像度の120fps時系列8条件について、頭部に固定した根元・中央・毛先の最大前方速度の時刻を厳密な昇順で検査する。接触までの速度を使い、振り戻しの速度と混同しない。先端の最大速度が根元・中央より大きいことも確認する。

30fpsでは0.13秒の攻撃が少数frameとなるため、等倍描画・操作感の最終判断は実機Human Verificationで行う。
