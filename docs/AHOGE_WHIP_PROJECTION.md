# ロングのムチ運動と全体補正

関連: #102 / PR #105 / AHOGE_WHIP_MOTION_DESIGN.md
基準: `715428586f4a88a56ab04f6f6714cd5b59d57659`。
本書の追加仕様は旧FollowThroughとパリィの初期振幅より優先する。

## ロング全体の基本方針

Human Decision: ロングタイプのアホ毛は基本的にムチのように動かす。攻撃だけを一枚の棒として振る方式にはしない。
頭部に固定した根元が駆動源となり、中央、毛先の順に遅れ・しなり・振り戻しが伝わる。待機は小さく、溜めでは後ろへ垂れ、攻撃ではしなりを解放し、接触後は下へ振り抜いて戻す。パリィは同じ柔らかい毛束を近距離で返す動作であり、長距離攻撃の縮小版ではない。
これは2D固定メッシュによる制御付きの表示方針。完全物理への置換、入力による毛先の直接操作、勝敗判定の変更は行わない。SHORTの投擲・アホ毛不在時のDODGEは維持する。

## 接触前に維持する基準

- 回転・軸方向伸長の基準は、そのframeで巻き込んだ毛先ではなく、接触時の伸び切った形の根元→先端ベクトルに固定する。
- 現在の毛束の形はActionMotionの根元側→中央→末端という解放に任せる。
- 接触までの進行qに対する追加射程補正は、通常q^4・最大チャージq^6。中間チャージは指数を4〜6で補間する。
- 全体回転はsmoothstep(0,0.95,q)で接触時の向きへ展開する。
- 接触時q=1では先端位置誤差2px以下、塗りと幅、根元固定を維持する。
- 幅方向へ射程倍率を重ねず、前frameのskewを累積しない。

## 接触後: より下まで振り抜く

旧前方30px・下方22pxの浅い振り抜きを置換する。

- 初期目標は固定した接触点から前方42px・下方100px。左右反転はfacingへ従う。
- 最終目標はBattle領域の12px内側に収める。相手の現在位置は追尾しない。
- 下側に余白が少ない条件でも、元の接触点より下へ明確に進む。全体縮小だけで振り抜きや見切れを隠さない。
- 接触後0.10秒を振り抜き時間とする。STRIKE残り時間とCOOLDOWN序盤を連続した表示時間として用い、serverの攻撃・防御時間を延長しない。
- 毛先側に下向きの曲げを残しながら、固定接触点から下への経路を進む。接触後の補正は実際の毛先を使い、途中の曲げで目標を通り越してから戻る逆行を避ける。
- 振り抜き完了後、根元側から毛先へ時間差を付けて0.18〜0.24秒でC字へ復帰する。COOLDOWN開始時に振り抜きを打ち切らない。
- PARRY/DODGE/STAGGER/非表示/ROUND_LOCKEDへの割込みで旧振り抜きを継続しない。現在形状から各状態の復帰・防御へ接続する。
- 確定Hit通知は従来の重複・古い通知抑止を維持し、再生した接触後も同じ振り抜き経路へ進む。

## パリィ: 曲がったまま払い幅を拡大

根元〜弧長62%は固定、62〜94%で末端の追加曲げを分配する構造は維持する。
準備/払い/反動の初期角度を+0.24 / -0.95 / +0.12 radへ変更する。全体角度ではなく、先端側の区間への追加角度である。
元のC字、区間長、断面幅を維持する。相手頭部へ届かせる追加伸長・全体の振り上げ・頭部の大ジャンプは使用しない。
0.18秒の有効時間、0.07秒のJust受付、現在形状からの0.055秒の接続は変えない。

## 検証

既存24連続動作・48接触・48パリィ・歪み蓄積防止・オンライン回帰を維持する。
120fps時系列8条件の根元→中央→毛先の最大前方速度順序と、先端の最大速度が最大という検査も残す。

追加検査:
- 実メッシュ先端が接触から下へ動くこと。単なる設定値比較ではなく実HUDの座標を測る。
- 通常/最大チャージ・左右・2解像度・相手LONG/SHORT・30/60/120fps。接触後も時間を刻み、COOLDOWN序盤まで振り抜きが継続すること。
- 振り抜き終了点の画面内包含と、相手の移動に追従しないこと。先端が接触より最低35px下へ進むことを基準とする。
- パリィ先端の変位は1280幅換算で60px以上、110px以下。以前の約35px程度から明確に増えたことを確認する。
- パリィの固定部、C字の曲率、三角形面積、外周交差、幅・弧長、割込みを確認する。
- 等倍とスローの実描画を保存する。数値成功をムチらしさの最終合格と置き換えない。
