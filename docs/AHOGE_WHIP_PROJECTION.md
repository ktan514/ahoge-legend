# ロングのロープ状モーションと接触表示

関連: #102 / PR #105 / AHOGE_WHIP_MOTION_DESIGN.md
基準: `a51147564ad0f9a17a935e4306f4778dfd4efb37`。
本書は旧FollowThrough・全体補正の初期値より優先する。Human Verificationは引き続きNGであり、実装やCIだけで合格へ変更しない。

## 要求

ロングは溜め・解放・振り抜き・復帰・近距離パリィまで、柔らかいロープとして扱う。根元を頭部に固定し、曲がっている場所が根元側から中央、毛先へ走る。一本の直線を回転・拡縮しただけの攻撃は不採用。
叩いた後も毛先は勢いを保って下へ通過し、それから回収する。チャージ量が増すほど攻撃開始後の解放と接触までを速くする。
2D固定メッシュ・UV/index・太さと根元の維持、SHORT投擲、アホ毛不在中のDODGE、サーバー権威の勝敗・防御・切断仕様を維持する。

## チャージ速度の定義

攻撃速度は入力を離してから接触するまでの速度を指す。連打速度やCOOLDOWN短縮と混同しない。
現行CombatConfigとserver combatAttackTimingには既に通常WINDUP 0.18秒/STRIKE 0.20秒、最大チャージWINDUP 0.08秒/STRIKE 0.13秒、接触比率0.70がある。30Hzサーバーでは通常6+5 tick、最大3+3 tickで接触する。
この実時間差を見た目の曲がり伝播へ使用する。見た目だけ速くして判定を置き去りにせず、通常/中間/最大チャージで接触までの時間が非増加であることを検査する。既存値を新規に追加したと報告しない。SHORTやサーバーの共通時間を根拠なく変更しない。

## 形状と曲がりの伝播

断面中心線の区間長を保持し、区間角度から固定メッシュを再配置する。大きな曲がりの帯を毛束の弧長方向へ移し、先端は最後まで遅れる。接触瞬間には先端側の巻き込みをほどくが、根元側には柔らかい弧を残す。
チャージは先端を小さい輪に巻いて短く見せるのではなく、後方へ落ちる開いた曲線とする。チャージ解放は現在形状から接続する。
接触後は小さい一定角度を足すだけではなく、根元側から追従する曲がりを毛先へ送り、先端が下へ進む間も中間部の曲率が変化する。全体の幅は一定で、直線姿勢のまま全体を縮めて戻すことを主動作にしない。

## 接触と慣性の連続性

- 接触前の位置補正は接触姿勢を基準にし、現在の巻き込んだ先端へ全体回転を毎frame当て直さない。
- 接触時は実毛先と相手の描画輪郭の誤差2px以下、幅・根元を維持する。
- 接触後は相手座標を固定し、追尾しない。下向き軌道は開始速度0のsmoothstepで止めず、接触を通過して下へ進む曲線とする。
- 画面下側の余白を使用する。見切れや一律の縮小で振り抜きを隠さない。
- 振り抜きはSTRIKEの残りとCOOLDOWN序盤を同じ時計で継続する。毛先が下へ通過する前にC字への回収を開始しない。
- 先端の最低位置だけでなく、接触前後の速度・曲率・往復の連続フレームを検査する。

## Hit通知で攻撃を巻き戻さない

既に接触姿勢を通過した攻撃へ遅れてHit通知が来ても、force_contactで直線姿勢や接触時刻へ戻さない。途中のfollow/cooldown時計・区間角度・保存した接触点を維持する。
表示上まだ接触前なら、サーバーの確定結果へ一度だけ追従する。表示が先行している場合はそのまま進める。古い通知・重複・パリィ中断・非表示・ROUND_LOCKEDの抑止を維持する。
「表示が接触を通過済み」を、実フレームの座標・時間で検査する。通知の到着回数を未取得の動画だけから断定しない。

## パリィ

根元側62%を固定し、曲がった先端側の短い毛束で近距離を払う。全体の大振り・遠距離伸長・相手頭部への追従は使わない。
先端カーブの開閉だけを払いと誤認しない。払い量だけでなく、湾曲した末端の短い弧と戻りを実描画で確認する。PARRY 0.18秒、Just 0.07秒は維持する。

## 検証と再現

通常Godot、既存の24連続動作・48接触・48パリィ・48振り抜き・変換の歪み防止・オンライン回帰を維持する。新しい要件と矛盾しない既存しきい値を下げない。
追加検査は、チャージと接触時間の対応、伝播する曲がりの実頂点、接触後の下向き継続、遅延Hit通知による巻き戻し抑止、通常/最大チャージ・左右・複数fps、実描画とする。サンプル幾何学検査を連続全域の非交差証明とは扱わない。

CI結果の再現用に、検査対象HEADのクライアントソースと使用したGodot Linux実行ファイルを別artifactへまとめる。git追跡済みのクライアント・テスト・素材・必要スクリプトだけを許可リストで収録し、.git、.env、サーバー設定、credentialは含めない。Godotの著作権表示も収録する。手元で同じHEADの実描画を比較し、CIと実機を混同しないための検証資料であり配布製品ではない。
