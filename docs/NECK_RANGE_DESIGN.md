# 首の前後可動域（段階調整1）

関連: #102 / PR #105。基準: 2d28f6ca944b9c44a3ee8f7e6da5c7f5e34c6696。

## 今回の要求

まず首の前後移動だけを調整する。基準位置から後方へ頭部直径の0.5倍、前方へ0.5倍を最大可動域とする。端から端までの移動量は頭部直径1個分である。首の断面を新しく描く意味ではなく、頭部の水平移動として表す。

Dは回転していない頭部の表示直径とする。現在の2D頭部素材では透過余白を除いた頭部画像の横幅に描画倍率を掛けた値を使用する。アホ毛を含めず、回転後の外接矩形やウィンドウの余白も直径に含めない。左右とも同じDを使用する。仮の円形頭部では輪郭を含む描画直径を使用する。

前方基準の指定量rを[-0.5,+0.5]へ制限し、表示変位X = facing × D × rとする。P1は前が右、P2は前が左。無効な数値は受け付けず、前の有効な位置を保持する。画面の拡大縮小ではDと移動量を同じ倍率にする。

## 実装の責務

`src/ui/neck_range_fighter.gd`は既存のBattleFighterVisualを継承し、頭部直径の取得、直径比の指定、首の単独調整モードを追加する。BattleHUDもこの実装を使用する。通常時は既存BattleFighterVisualの処理をそのまま呼び、攻撃・チャージ・パリィのキー値、時刻、判定を変更しない。

明示的な単独調整中だけ、上下動・傾き・呼吸・攻撃動作の自動再生を停止する。頭部のXだけを変更し、既存の頭頂部anchor更新を経由して同じframeでアホ毛の根元を追従させる。毛束内部の形と太さは固定する。直線素材対応ZIPの有無のどちらでも、現在設定されている素材・待機形を使う。

これは段階調整用の表示APIであり、通常ゲームに新しいマウス操作やサーバーへ送る移動入力を追加するものではない。各攻撃で可動域を何割使うかの調整は後続。今回、全アクションを一律に最大振幅へ拡大しない。通常モーションの端の見切れ防止も変更しない。

## 確認ツール

既存MotionPreviewから「首の前後だけ調整」で開く。直接起動:

```bash
godot --path . res://tools/motion_preview/NeckRangePreview.tscn
```

同じBattleHUDから取得した実際のfighterを中央の確認領域へ移す。大きさを縮めて可動域を隠さず、既存の表示直径のまま前後0.5Dを確保する。相手との距離や通常のBattleの配置は変更しない。

スライダーと数値入力は直径比[-0.5,+0.5]。後端・基準・前端のボタン、往復再生、向き、内部解像度、PNG保存を用意する。移動量、D、片側可動量を表示する。基準位置と両端のガイドを描く。手動操作は往復再生を停止する。往復の速度は観察用であり攻撃速度へ反映しない。

PNG保存先はartifacts/neck-range/。画面や設定を変えても入力範囲が縮まらない。閉じる・他のSceneへ戻ることで調整専用状態を破棄する。
